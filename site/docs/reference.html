Verdicts

VerdictWhen
ON TIMEruns exist, median lag ≤ --late, under 25% very late, nothing missed
LATEmedian lag above --late, or ≥ 25% of runs very late
DROPPINGat least one slot missed
NOT FIRINGslots came due and no scheduled run was created at all
DISABLEDworkflow state is not active (e.g. disabled_inactivity)
INVALIDno valid cron, or the file does not parse
NO DATAno slot has come due in the window

Slot states

ontime (≤ on-time), late (≤ late), verylate, overdue (no run yet), missed, pending (not due yet).

Times are epoch milliseconds in slots, ISO strings at the top level. Durations are milliseconds.

Exit codes

0 ok (or nothing matched --fail-on) · 1 a workflow matched --fail-on · 2 usage error (an unknown option, a bad --since / --days) / invalid cron · 3 GitHub API error (rate limit, not found, auth), or a catchup --dispatch dispatch that failed.

MCP tools

schedule_report returns the Markdown report plus compact JSON; catchup_plan returns the steps catchup would take (never dispatches); cron_explain returns next fire times, shortest interval and the minute-0 flag. All are annotated readOnlyHint: true.
