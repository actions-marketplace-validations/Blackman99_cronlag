Fixed rules

  • A run is attributed to a slot at most 24 hours after it (GitHub drops scheduled events queued longer).
  • Runs created up to 2 minutes before a slot count for it (clock skew).
  • A slot with no run is missed once it is 24h old or a later slot already got its run; until then it is overdue.
