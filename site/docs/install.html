Install

Run without installing

npx github:Blackman99/cronlag owner/repo

Requires Node.js 18.17 or newer. The package ships a single bundled file with no runtime dependencies, so npx from GitHub is quick. It is not on the npm registry yet; once it is, npx cronlag will work too.

Install

npm install -g github:Blackman99/cronlag      # from git
npm install -g ./cronlag-0.1.0.tgz             # from the release tarball

Release tarballs: GitHub Releases.

Tokens

cronlag looks for a token in --token, then GITHUB_TOKEN, then GH_TOKEN, then gh auth token.
